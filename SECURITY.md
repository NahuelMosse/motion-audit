# Security policy

## Supported versions

Only the latest version published on npm (`latest`) receives fixes.

## Reporting a vulnerability

Report it privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.
Include the version, the command you ran and what it did. You get an answer within 7 days.

motion-audit opens the page you give it in a headless browser and reads what it measures. A way for an audited page to
run code on the host, read or write files outside the report, or reach the tool's own process counts as a vulnerability.
